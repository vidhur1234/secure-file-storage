Project Demo & Tampering Verification Guide Viva Demonstration
How to demonstrate AES-256 & SHA-256 Tamper Detection:
  1. All encrypted files are stored on disk in storage/encrypted/ as <UUID>.enc.
  2. Notice that if you open any .enc file in Notepad or VS Code, it contains pure random ciphertext — no plaintext words exist.
  3. Simulate Tampering (Attacker / Ransomware): Open any .enc file in Notepad, change/add/delete a single character, and save it.
  4. Click "Download & Verify" on that file in this UI.
  5. The System will immediately catch it! AES-256-GCM authentication tag verification and SHA-256 digest comparison fail. The file download is aborted, an alert is displayed, and a TAMPERED security incident is recorded in the Audit Logs!
PowerShell command to tamper with a file for demo: Add-Content -Path "storage\encrypted\*.enc" -Value "MALICIOUS_BYTES"
