Secure File Upload

Upload documents with automatic in-memory AES-256-GCM encryption and SHA-256 hashing

How Your File Is Protected During Upload:
1. SHA-256 Digest: Original plaintext hashed to generate integrity fingerprint.
2. AES-256-GCM: A unique 256-bit AES key & 12-byte IV encrypts file bytes in RAM.
3. Envelope Security: File key is wrapped using Server Master Key before DB storage.
4. Zero Plaintext Disk: ONLY ciphertext (.enc) written to disk.
